# XOps Labs

XOps Labs builds open-source tools for AI-native operations: reliability, observability, cost governance, and secure platform automation for teams running modern AI workloads.

We focus on practical infrastructure that fits into the stacks engineers already use: Prometheus, Grafana, OpenTelemetry, Kubernetes, CI/CD, and cloud-native security workflows.

## What We Build

- Observability tools for AI and LLM workloads
- FinOps-friendly telemetry for usage, cost, and budget signals
- Secure operations patterns for production platforms
- Cloud-native utilities that are self-hosted, inspectable, and automation-ready

## Projects

### [llm-usage-exporter](https://github.com/xops-labs/llm-usage-exporter)

A self-hosted Prometheus exporter for LLM usage, token consumption, request volume, and USD cost telemetry across OpenAI, Azure OpenAI, Anthropic Claude, Google Gemini, and AWS Bedrock.

It helps platform, SRE, FinOps, and engineering teams bring AI spend into the same operational feedback loop they already use for latency, errors, saturation, and infrastructure cost.

## Principles

- Open source by default
- Self-hosted and vendor-neutral
- Low-cardinality, production-safe telemetry
- Built for Prometheus, Grafana, OpenTelemetry, and Kubernetes
- Security, governance, and cost visibility treated as first-class operations concerns
